# 한국 주식시장 자동매매 시스템

## ⚠️ 주의사항

### 1. 특수 종목 제외 필요

| 종목코드 | 종목명 | 사유 |
|----------|--------|------|
| A0126Z0 | 삼성에피스홀딩스 | 종목코드에 'Z' 포함 (보통주 아님) |

KOSPI200, KOSDAQ150 나머지 종목은 모두 보통주에 해당.  
해당 종목은 **DB 적재 시 제외**하거나 **모델 학습 데이터에서 제거** 필요.

---

### 2. 재무 데이터 미가공 (데이터 정합성 미보장)

현재 재무 관련 데이터는 재무제표에서 수집한 **원본 그대로** 사용 중.

**문제점:**
- 일부 종목은 **분기별 누적** 수치
- 일부 종목은 **4분기 연간 누적** 수치
- **같은 종목 내에서도 두 케이스가 혼용**되는 경우 존재

**해당 항목:** 포괄손익계산서 (매출액, 영업이익, 당기순이익)

> 데이터 정합성이 보장되지 않음 -> 학습 데이터에서 재무 데이터를 아예 제거하는 것으로 확정
